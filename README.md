# 🏔️ 小小修仙者

> 这是一个挂机修仙小游戏，小小修仙者一步步登顶最高峰。

## 📖 游戏简介
在游戏中，你将扮演一名初出茅庐的小小修仙者。通过挂机修炼、下山历练、结交道侣、加入宗门，一步步突破境界，最终登顶修仙界的最高峰！

## ✨ 核心玩法
- **🧘 闭关修炼**：轻松挂机，自动吸纳天地灵气，离线也能积累修为。
- **⚔️ 秘境历练**：探索各大秘境，斩妖除魔，获取珍稀法宝与天材地宝。
- **🏪 坊市交易**：自由买卖修仙资源，炼丹炼器，打造专属修仙之路。
- **🏯 宗门系统**：加入宗门，与同门切磋交流，参与宗门大比，共抗外敌。
- **💖 道侣结缘**：寻觅仙途伴侣，结成道侣，体验双修互动的独特乐趣。
- **🏔️ 登顶最高峰**：不断打破极限，飞升渡劫，最终傲视群雄，登顶巅峰。
